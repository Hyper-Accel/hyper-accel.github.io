# HyperAccel Blog Editor

Hugo Markdown 글을 PaperMod의 읽기 화면과 같은 폭과 타이포그래피로 편집하는 로컬
웹 에디터입니다. 제목과 본문을 화면에서 직접 수정하고, 클립보드 이미지를 커서 위치에
붙여넣을 수 있습니다.

## 최초 설치

저장소 루트에서:

```bash
./tools/editor/install.sh
```

설치 후에는 어느 디렉터리에서든 다음 명령만 실행합니다.

```bash
techblog-editor
```

명령이 편집기와 Hugo 서버를 함께 실행하고 기본 브라우저에서 편집기를 자동으로 엽니다.

- 편집기: <http://127.0.0.1:4173>
- 실제 Hugo 결과: <http://127.0.0.1:1413>

전역 명령을 설치하지 않고 실행하려면 저장소 루트에서
`./tools/editor/run.sh`를 사용할 수도 있습니다.

## 사용

- 왼쪽에서 글을 고른 뒤 제목과 본문을 바로 편집합니다.
- 이미지 복사 후 본문 원하는 위치에서 `Cmd+V`/`Ctrl+V`를 누릅니다.
- 이미지 파일을 본문으로 드래그하거나 툴바 이미지 버튼으로 선택할 수도 있습니다.
- 이미지는 현재 글 번들의 `images/pasted-YYYYMMDD-HHMMSS-*.png` 형태로 저장됩니다.
- `Cmd+S`/`Ctrl+S` 또는 **저장** 버튼으로 저장합니다.
- 서버는 저장 후 Hugo 렌더링을 실행하고, 실패하면 Markdown 파일을 자동 복구합니다.
- **실제 화면** 버튼은 저장된 글을 Hugo 페이지로 엽니다.

## 로컬 에이전트로 글 수정하기

왼쪽 패널에서 **AI** 탭을 열면 컴퓨터에 설치된 Codex, Claude, OMO 가운데 원하는
에이전트를 선택할 수 있습니다. 각 에이전트는 평소 로컬에서 사용하던 설정과 스킬을
그대로 불러옵니다.

1. 수정할 글을 연 뒤 **AI** 탭에서 에이전트를 선택합니다.
2. 요청을 입력하고 **요청 보내기**를 누릅니다. `$fluent-korean`처럼 로컬에 설치된
   스킬도 요청에 직접 지정할 수 있습니다.
3. 에이전트가 작업을 마치면 현재 글은 왼쪽에, 수정 제안은 오른쪽에 표시됩니다.
4. 가운데 화살표로 변경 단위마다 현재 글과 수정 제안 중 하나를 선택합니다. 상단의
   **현재 글 모두 선택**과 **AI 제안 모두 선택** 버튼으로 한쪽을 한 번에 고를 수도
   있습니다.
5. **선택한 내용 적용**을 누르면 선택 결과가 편집기에 반영됩니다. 이 단계에서는 아직
   원본 파일이 바뀌지 않으므로, 내용을 다시 확인한 뒤 **저장**을 누릅니다.

병합 검토를 닫아도 수정 제안은 사라지지 않습니다. 왼쪽 대화에 표시되는
**수정 제안 다시 열기** 버튼으로 검토 화면을 복원할 수 있습니다.

## 안전장치

- `content/posts/<slug>/index*.md` 밖의 파일은 API에서 열 수 없습니다.
- 외부에서 파일이 바뀌면 revision 충돌로 저장을 막습니다.
- PNG, JPEG, GIF, WebP 이미지만 허용하며 최대 크기는 15MB입니다.
- Hugo shortcode는 에디터에서 보호된 블록으로 표시되고 원문 그대로 다시 저장됩니다.
- 에이전트는 현재 글의 사본이 들어 있는 임시 Git worktree에서만 작업합니다. Codex와
  OMO는 작업공간 쓰기 권한으로 제한되며, Claude는 로컬 sandbox를 반드시 사용합니다.
- 에이전트가 만든 변경은 원본 글에 자동으로 덮어쓰지 않습니다. 병합 화면에서 선택하고
  편집기의 **저장** 버튼을 눌러야 실제 Markdown 파일에 반영됩니다.

## 개발 검증

`techblog-editor`를 실행한 상태에서 다른 터미널을 열어 다음 명령을 사용합니다.

```bash
cd tools/editor
bun run check
bun run build
bun run e2e
AGENT_PROVIDER=codex bun run e2e:agents
AGENT_PROVIDER=omo bun run e2e:agents
AGENT_PROVIDER=claude bun run e2e:agents
```

실제 에이전트 검증은 각 실행 파일이 로컬에 설치되고 인증된 환경에서 실행해야 합니다.
